# Student Notes Hub

A subject-wise notes portal built with React, Node.js, Express, and MongoDB.

## Requirements

- Node.js
- MongoDB running locally, or a MongoDB connection string

## Setup

1. Install dependencies:

   ```bash
   npm install
   ```

2. Create `.env` from `.env.example` and set the admin credentials, JWT secrets, MongoDB URI, and Cloudinary credentials:

   ```env
   CLOUDINARY_CLOUD_NAME=your-cloud-name
   CLOUDINARY_API_KEY=your-api-key
   CLOUDINARY_API_SECRET=your-api-secret
   AI_PROVIDER=gemini
   GEMINI_API_KEY=your-google-ai-studio-key
   GEMINI_MODEL=gemini-2.0-flash
   ACCESS_TOKEN_SECRET=use-a-long-random-secret
   REFRESH_TOKEN_SECRET=use-another-long-random-secret
   ```

   Use different long random values for both JWT secrets. Student accounts are created from the Student login page. Access tokens expire after 15 minutes by default; the HTTP-only refresh cookie keeps the session active for 7 days and is rotated after every refresh.

3. Start the server:

   ```bash
   npm start
   ```

4. Build the React frontend before starting production mode:

   ```bash
   npm run build
   npm start
   ```

5. Open `http://localhost:3000`.

For frontend development with Vite and the Express API:

```bash
npm run dev
```

`npm run dev` starts the Node server and Vite frontend together. To run them separately, use `npm start` and `npm run frontend:dev`.

The React frontend is in `frontend/`. It provides route-based Home, About, Notes, Contact, Admin, and Subject views with shared theme, navigation, loading, error, upload, and delete state.

## Project layout

```text
backend/server.js          Starts the Express application
backend/models.js          MongoDB data models
backend/config/             Database, authentication, and Cloudinary setup
backend/middleware/         Request authentication, upload, and error handling
backend/routes/             URL paths, HTTP methods, and middleware
backend/controllers/        Code that handles API requests and responses
backend/utils/              Shared API helpers and AI provider functions
frontend/src/               React pages, components, styles, and API calls
frontend/dist/              Built frontend files; regenerated by npm run build
frontend/legacy-pages/      Older standalone HTML pages kept for reference
scripts/                    Small utility and learning scripts
uploads/                    Local upload storage and subject folders
Project_plan.txt            End-to-end project roadmap
.env                        Local environment settings; do not commit
```

The frontend and backend source are separated into `frontend/` and `backend/`.
The root `package.json` and `.env` are shared project configuration. The older
standalone pages are in `frontend/legacy-pages/` and are not used by the current
React app. Do not edit generated files in `frontend/dist/` directly.

## Features

- Browse notes by subject
- Admin-only note uploads and deletion
- MongoDB note metadata storage with Cloudinary file storage
- Upload size is configured with `MAX_FILE_SIZE_BYTES` in `.env` (defaults to 10 MB)
- Student registration and login with hashed passwords
- Short-lived access tokens and rotating refresh tokens
- Admin role protection for uploads and deletion
- Contact form storage
- Subject-aware AI study assistant on every subject notes page. Gemini can be used with a Google AI Studio API key and `AI_PROVIDER=gemini`; free-tier limits depend on the Google account and region.
