STUDENT NOTES HUB
END-TO-END PROJECT PLAN

Project purpose
---------------
Build a secure, responsive web application where students can browse and
download subject notes, contact the team, and use an AI study assistant.
Administrators manage note uploads and deletion.

Technology stack
----------------
- Frontend: React, React Router, Vite, HTML, CSS, JavaScript
- Backend: Node.js and Express
- Database: MongoDB with Mongoose
- File storage: Cloudinary
- Authentication: bcryptjs, JWT access tokens, rotating refresh tokens
- AI: Node.js service code calling Gemini or OpenAI APIs
- Tests/build: Node.js scripts and Vite
